# my-sysadmin-scripts

## Структура репозитория

	my-sysadmin-scripts/

		|-README.md # одна строка: что делает скрипт

		|-script.sh # сам скрипт

		|-sample_output.txt  # пример вывода

## Что делает скрипт script.sh

Написанный скрипт позволяет фильтровать логи по ключевым словам. При этом было реализовано 2 режима работы:
- Использование фильтрации по словам с объединением результатов и исключением дубликатов
- Фильтрация по каждому слову отдельно и формирование отчета с указанием хедера по словам фильтрации
